# Screenshots

Capture these from a running instance and drop the PNG files in this directory.
The README links to them directly.

| File | What to capture |
| ---- | --------------- |
| dashboard.png | Monitor list in light mode with at least one up and one down monitor |
| monitor.png | Monitor detail page with the response time chart populated |
| status.png | Public status page with the operational banner and uptime bars |
| dark.png | Dashboard in dark mode (switch the OS theme, or emulate it in devtools) |

Crop to the browser viewport, 1280x800 or larger. Keep the default theme
untouched so screenshots match a fresh install.
